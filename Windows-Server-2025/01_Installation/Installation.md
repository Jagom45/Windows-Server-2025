# Windows Server 2025
- This file will tell you how to install windows server 2025

# Installation
- On the Windows Server Setup, select the language to install and the time and currency format
- On the Select Keyboard settings, select a keyboard or input method
- On the Select setup option, select Install Windows Server and check the I agree everything will be deleted including files, apps, and settings
- On the Select Image, select Windows Server 2025 Standard Evaluation (Dektop Experience)
- On the Applicable notices and license terms, click on Accept
- On the select location to install windows server select an unallocated space
- On the Ready to Install window, click on Install
- On the Install Windows Server window, let the installation finish
- Enter a password and re-enter it again
- On the VMware Workstation, click on VM and the click on the Ctrl+Alt+Del button to get past the lockscreen
- On the lock screen, enter the password
- On the Send diagnostic data to Microsoft, click on Accept
